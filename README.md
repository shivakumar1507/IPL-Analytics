# IPL Analytics Dashboard

Interactive IPL analytics dashboard built using Tableau.

## Features
- Tournament overview dashboard
- Team-wise performance analysis
- Season trends visualization
- Interactive filters
- KPI cards

## Tools Used
- Tableau Public
- SQL
- Excel/CSV
